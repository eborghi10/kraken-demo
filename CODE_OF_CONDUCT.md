# Code of Conduct

This project follows the [Contributor Covenant v2.1][cc].

In short: be respectful, assume good faith, and critique code rather than
people. Harassment, personal attacks, and demeaning comments are not welcome.

Report problems by opening an issue, or privately to the maintainer listed in
the package manifests. Reports will be handled confidentially.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
